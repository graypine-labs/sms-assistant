# SMS Assistant

A personal SMS assistant. Text any question to **+1 844 372 1763** and get an automated answer by text message.

## How to opt in

You opt in by sending the first text. Send any message (for example, "Hi" or a question) to **+1 844 372 1763** from your own phone. By texting that number, you agree to receive automated SMS replies from this service.

- Replies go only to the phone number that texted us. We never text third parties.
- Message frequency varies with use (expected: only a few messages per month).
- Message and data rates may apply.
- Reply **STOP** at any time to stop receiving messages.
- Reply **HELP** for help.

## What it does

You ask a question by text; the assistant finds the answer and texts it back. Examples: weather, schedules, and general knowledge questions.

## Privacy

Your phone number is used only to reply to your own messages. No marketing, and your number is never shared.
